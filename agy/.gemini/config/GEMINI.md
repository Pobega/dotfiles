# Global Token-Saving Subagent Policy

- **Direct Fast-Path Exception**: Run single-step, low-output commands (`<50` lines, e.g. `git status`, `git diff --stat`) and scoped edits across `<=3` known files (`<=4` tool calls, `<80` changed lines, no noisy test runs) directly in the primary agent rather than paying 2-turn subagent dispatch/wakeup overhead.
- **Subagent Dispatch (`flash-offload`)**: For `4+` files, `>80`-line boilerplate, or iterative build/test loops, spawn `TypeName: "flash-coder"` (`Model: "flash"`, statically defined in `~/.gemini/config/agents/flash-coder.md` — never call `define_subagent`) and reuse its `conversationId` via `send_message` across sequential subtasks. When code edits are planned, skip `research` and let `flash-coder` do both file lookup and edits in one session (`<150`-word summary return). Reserve `research` (`Model: "flash_lite"` or `"flash"`) strictly for read-only exploration where no edits will follow.
- The user explicitly authorizes and prefers `Model: "flash"` (and `Model: "flash_lite"` for simple read-only lookups) in `invoke_subagent` calls instead of `Model: "inherit"` to conserve primary model tokens.
- **Milestone Context Pill (`~25+` steps)**: At natural milestone boundaries in longer sessions (`~25+` conversation steps, measured via `awk '/"type":"CHECKPOINT"/{b=0; s=0} {b+=length($0)+1; s++} END{printf "%d steps, ~%.1fk tok\n", s, (b/4000)+20}' <appDataDir>/brain/<conversation-id>/.system_generated/logs/transcript.jsonl`), proactively append a `/compact` or `session-handoff` suggestion as a single compact HTML pill one-liner (`<span style="background: rgba(<r>, <g>, <b>, 0.15); color: <hex>; padding: 2px 6px; border-radius: 4px; font-family: monospace;">Context: <steps> steps (~<tokens>k tok) — <short recommendation></span>`, using green `#2ecc71` / `46, 204, 113` `<50k`, yellow `#f1c40f` / `241, 196, 15` `50k–95k`, or red `#e74c3c` / `231, 76, 60` `>95k`) without extra vertical spacing or headings before starting the next task.
